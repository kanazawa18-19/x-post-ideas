# X投稿ネタ自動生成ツール｜セットアップマニュアル（パターン2：GAS版）

> **プログラムの知識は一切不要です。**
> Googleスプレッドシートのセルに情報を入力するだけで使えます。
> 一度設定すれば、毎日自動で投稿ネタを生成してSlackに届けます。

---

## このツールでできること

- 業界ニュース・最新トレンドをAIがWeb検索して自動収集
- Xアルゴリズムの最新動向を参照
- 今日の記念日・何の日を参照
- 上記をもとにXの投稿案を10個生成
- Slackの指定チャンネルに自動投稿

---

## 必要なもの（2つだけ）

| 必要なもの | 説明 | 費用 |
|---|---|---|
| Anthropic APIキー | AIを動かすための鍵 | 従量課金（1回あたり約1〜3円） |
| Slack Incoming Webhook URL | SlackへAIが投稿するための専用URL | 無料 |

---

## セットアップの全体像

```
①スプレッドシートをコピーして開く
     ↓
②「設定」シートに自分の情報を入力する
     ↓
③一度だけ「テスト実行」して動作確認
     ↓
④自動実行のスケジュールを設定する（1回だけ、以後は自動）
```

---

## STEP 1｜スプレッドシートをコピーする

1. 配布者から受け取ったリンクをクリックしてスプレッドシートを開く
2. 画面上部メニューの **「ファイル」→「コピーを作成」** をクリック
3. 「コピーを作成」ボタンをクリック（名前はそのままでOK）
4. 自分のGoogleドライブにコピーが保存されます

---

## STEP 2｜Anthropic APIキーを取得する

> AnthropicはAIを提供している会社です。このAIが投稿ネタを考えてくれます。

1. **https://console.anthropic.com** をブラウザで開く
2. 「Sign Up」をクリックしてメールアドレスでアカウントを作成
3. ログイン後、左メニューの **「API Keys」** をクリック
4. **「Create Key」** ボタンをクリック
5. 名前は何でもOK（例：`x-post`）→「Create Key」をクリック
6. 画面に表示された **`sk-ant-`** から始まる文字列をコピーしてメモ帳などに保存

> **重要：** このキーは一度しか表示されません。必ず今コピーしてください。

**料金の目安：**
1日4回実行しても月額300〜500円程度です。
Anthropicのコンソール画面から利用金額をいつでも確認できます。

---

## STEP 3｜Slack Webhook URLを取得する

> Webhook URLは「このURLに送ったメッセージをSlackに届ける」という専用の宛先です。

1. **https://api.slack.com/apps** をブラウザで開く（Slackにログインした状態で）
2. **「Create New App」→「From scratch」** をクリック
3. App名に **`投稿ネタBot`** と入力し、使っているSlackワークスペースを選んで **「Create App」**
4. 左メニューの **「Incoming Webhooks」** をクリック
5. 右上のスイッチを **「ON」** にする
6. ページ下部の **「Add New Webhook to Workspace」** をクリック
7. 投稿先のSlackチャンネルを選んで **「許可する」**
8. 画面に表示された **`https://hooks.slack.com/services/`** から始まるURLをコピーしてメモ帳などに保存

---

## STEP 4｜スプレッドシートに情報を入力する

コピーしたスプレッドシートを開き、**「設定」シート**（画面下部のタブ）をクリックしてください。

以下のセルに情報を入力します。

---

### A列（項目名）・B列（入力欄）の構成になっています

| セル | 項目 | 入力する内容 |
|---|---|---|
| **B2** | 名前 | あなたの名前（例：山田太郎） |
| **B3** | Anthropic APIキー | STEP 2でコピーした `sk-ant-...` |
| **B4** | Slack Webhook URL | STEP 3でコピーした `https://hooks.slack.com/...` |
| **B5** | ペルソナ | あなたのXアカウントの自己紹介・専門領域 |

**ペルソナの書き方例：**
```
フリーランスのWebデザイナー。UI/UX・Figma・副業について発信している。
```
```
人事労務・採用のプロ。給与計算・社会保険・採用実務の実体験を発信。
```

---

次に **「コンテンツの柱」シート**（下部タブ）を開いてください。

**A列** に、発信したいテーマを1行に1つ入力してください（3〜10個が目安）。

| A列 |
|---|
| Webデザインのトレンド紹介 |
| Figmaの使い方Tips |
| 副業・フリーランスの実体験 |
| クライアントとの付き合い方 |

---

次に **「キーワード」シート**（下部タブ）を開いてください。

**A列** に、トレンドを追いたいキーワードを1行に1つ入力してください（10〜20個が目安）。

| A列 |
|---|
| Webデザイン |
| UI/UX |
| Figma |
| フリーランス |
| 副業 |

---

## STEP 5｜テスト実行する

情報の入力が終わったら、一度動作確認をします。

1. スプレッドシートのメニューバーに **「投稿ネタ生成」** というメニューがあります
2. **「投稿ネタ生成」→「今すぐ実行」** をクリック
3. 以下の画面が出たら **「続行」または「詳細」** をクリックして進めてください

> **「このアプリはGoogleによって確認されていません」という画面が出た場合：**
> 「詳細」→「安全でないページに移動（安全）」→「許可」の順にクリックしてください。
> これは自分でコピーしたスクリプトなので安全です。初回のみ表示されます。

4. 1〜3分ほど待つとSlackに投稿ネタが届きます

Slackに届いたら設定完了です。

---

## STEP 6｜自動実行のスケジュールを設定する（1回だけの作業）

このSTEPを完了すると、毎日自動で実行されます。一度設定すれば以後は何もしなくてOKです。

1. スプレッドシート上部メニューの **「拡張機能」→「Apps Script」** をクリック
2. 新しいタブでスクリプトエディタが開きます（コードが書いてありますが触らなくてOK）
3. 左メニューの **時計のアイコン（「トリガー」）** をクリック
4. 右下の **「トリガーを追加」** をクリック
5. 以下のように設定して **「保存」** をクリック：

| 項目 | 選択内容 |
|---|---|
| 実行する関数を選択 | `main` |
| イベントのソースを選択 | 時間主導型 |
| 時間ベースのトリガーのタイプ | 日タイマー |
| 時刻 | 投稿ネタが欲しい時間（例：午前7時〜8時） |

6. 保存後、自動的にトリガー一覧に追加されます

複数の時間帯に受け取りたい場合は、同じ手順でトリガーを追加してください。（例：朝7時・昼12時・夜22時の3回）

---

## 複数アカウント分を設定したい場合

「設定」シートの **3行目以降** に同じ形式で追加できます。

| セル | 内容 |
|---|---|
| B2 | 1人目の名前 |
| B3 | 1人目のAnthropicキー（全員同じキーでOK） |
| B4 | 1人目のSlack Webhook URL |
| B5 | 1人目のペルソナ |
| B7 | 2人目の名前 |
| B8 | 2人目のAnthropicキー |
| B9 | 2人目のSlack Webhook URL |
| B10 | 2人目のペルソナ |

「コンテンツの柱」「キーワード」シートも同様に、シートを人数分コピーして対応します。

## よくある質問

**Q. 実行したがSlackに届かない**
→ Webhook URLをコピーし直して設定シートに再入力してください。URLの前後にスペースが入っていないか確認してください。

**Q. 「APIキーが無効」というエラーが出た**
→ `sk-ant-`から始まるキーを再確認してください。コピー時に最初・最後の文字が切れていないか確認してください。

**Q. 実行に5分以上かかる**
→ Anthropic側の一時的な混雑の可能性があります。しばらく待ってから「今すぐ実行」を再度クリックしてください。

**Q. 自動実行が動いていない気がする**
→ Apps Scriptの「トリガー」画面を開き、トリガーが一覧に表示されているか確認してください。表示されていない場合はSTEP 6を再度実行してください。

**Q. APIキーの使用料金を確認したい**
→ https://console.anthropic.com にログインし、「Billing」メニューから確認できます。
