# X投稿ネタ自動生成ツール｜セットアップマニュアル（パターン3：Colab版）

> **一番かんたんなバージョンです。**
> インストール不要。ブラウザだけで使えます。
> 生成された投稿案はコピーして手動でSlackやメモに貼り付けて使います。

---

## このツールでできること

- 業界ニュース・最新トレンドをWeb検索で自動収集
- Xアルゴリズムの動向を参照
- 今日の記念日・何の日を参照
- 上記をもとにXの投稿案を10個生成
- 結果をブラウザ画面に表示（コピーして自由に使える）

> **GAS版・フル機能版との違い：**
> Slackへの自動投稿・定期実行はありません。
> 使いたいときにブラウザを開いて実行し、結果をコピーするスタイルです。

---

## Google Colabとは？

Googleが提供する無料のプログラム実行環境です。
ブラウザ上で動くため、パソコンに何もインストールする必要がありません。
Googleドキュメントを開くような感覚で使えます。

---

## STEP 1｜ノートブックを開く

1. 配布者から共有されたGoogle ColabのリンクをクリックするとColabが開きます
2. Googleアカウントでログインしていない場合はログインしてください
3. 画面上部の「ドライブにコピー」をクリックして自分のドライブに保存します

---

## STEP 2｜Anthropic APIキーの取得

1. https://console.anthropic.com にアクセス
2. 「Sign Up」からアカウントを作成（メールアドレスで登録可能）
3. ログイン後、左メニューの「API Keys」をクリック
4. 「Create Key」ボタンをクリック
5. 名前（例：`x-post-ideas`）を入力して「Create Key」
6. 表示されたキー（`sk-ant-...` で始まる文字列）をコピー

> **注意：** キーは一度しか表示されません。必ずコピーして安全な場所に保存してください。

**料金について：**
- 1回の実行で約1〜3円程度

---

## STEP 3｜APIキーを設定する

Colabのノートブックを開くと「セル」と呼ばれる入力ブロックが並んでいます。

**「① 設定」セル**を探して、以下の部分を書き換えてください。

```
ANTHROPIC_API_KEY = "ここにAPIキーを貼り付け"
```

例：
```
ANTHROPIC_API_KEY = "sk-ant-api03-xxxxxxxxxxxx"
```

---

## STEP 4｜自分の情報を入力する

同じく「① 設定」セルの中に、あなたのXアカウントの情報を入力する箇所があります。

### ペルソナ（自己紹介文）

```
PERSONA = "ここにあなたのキャラクター・専門領域を書く"
```

例：
```
PERSONA = "フリーランスのWebデザイナー。UI/UX・デザイン思考・副業について発信している。"
```

### コンテンツの柱（発信テーマ）

```
PILLARS = [
    "発信テーマ1",
    "発信テーマ2",
    "発信テーマ3",
]
```

例：
```
PILLARS = [
    "Webデザインのトレンド紹介",
    "Figmaの使い方Tips",
    "副業・フリーランスの実体験",
    "クライアントとの付き合い方",
]
```

### キーワード（トレンドを追いたい言葉）

```
KEYWORDS = ["キーワード1", "キーワード2", "キーワード3"]
```

例：
```
KEYWORDS = ["Webデザイン", "UI/UX", "Figma", "フリーランス", "副業"]
```

---

## STEP 5｜実行する

1. ノートブック上部の「ランタイム」→「すべてのセルを実行」をクリック
   （または画面左上の「▶ 再生ボタン」をセルごとに押してもOK）
2. 初回実行時は「このノートブックはGoogleが作成していません」と警告が出ます。
   「このまま実行」をクリックしてください。
3. 1〜3分ほど待つと、画面下部に投稿案が10個表示されます。

---

## STEP 6｜投稿案を使う

表示された投稿案の中から気に入ったものをコピーして、
X（Twitter）の投稿画面やSlack・メモアプリに貼り付けて使ってください。

---

## 次回以降の使い方

1. GoogleドライブからColabのノートブックを開く
2. 「ランタイム」→「すべてのセルを実行」をクリック
3. 結果をコピーして使う

## 毎回開くのが面倒な方へ

毎日開いて実行するのが手間な場合は、**パターン2（GAS版）**への移行をおすすめします。
GAS版はGoogleスプレッドシートで一度設定すれば、毎日決まった時間に自動で生成・Slack投稿してくれます。

---

## よくある問題と解決策

| 症状 | 原因 | 解決策 |
|---|---|---|
| 「APIキーが無効」と表示される | キーの入力ミス・コピーミス | `sk-ant-`から始まるキーを再確認。前後にスペースが入っていないか確認 |
| 何も表示されない | セルが実行されていない | 「ランタイム」→「すべてのセルを実行」を再度クリック |
| 実行中にエラーが出た | ネットワークの一時的なエラーなど | もう一度「すべてのセルを実行」を試す |
| 「ランタイムが切断されました」と出る | Colabの無料プランは90分で切断される | 再度接続して実行し直すだけでOK |
| 日本語が文字化けする | ブラウザの表示設定の問題 | ブラウザを最新版に更新する |
